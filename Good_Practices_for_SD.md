# Review Questions – Good Practices for Software Development

## Question 1
### Which point(s) were new to you?

Some of the points that were new and insightful to me are:

- The importance of **over-communicating** in a professional environment, especially informing team members early about delays, requirement changes, or technical issues.
- Using tools like **Github Gists, CodeSandbox, and Loom** to explain technical problems more effectively.
- Understanding that programming requires **deep work and sustained concentration**, and that preserving attention is an important professional skill.
- The importance of being mindful of teammates’ schedules and avoiding excessive messaging.


# Question 2
### Which area do you think you need to improve on? What are your ideas to make progress in that area?

One area I think I need to improve on is **asking better technical questions**.

Sometimes, while facing issues during development, I may not explain the problem clearly or provide enough details about what I already tried. This can make it harder for others to help quickly.

## My ideas to improve in this area are:

- Practice writing clear and structured problem statements.
- Include screenshots, error logs, and code snippets whenever asking for help.
- Learn to use tools like **Github Gists**, **CodeSandbox**, and screen recording tools for better explanations.
- Communicate progress and blockers regularly instead of waiting too long.
- Improve active listening during meetings and ask clarification questions immediately.

Improving these areas will help me become more productive, collaborative, and efficient as a software developer.
